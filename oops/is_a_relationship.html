Inheritance In Java

Inheritance is a fundamental concept in object-oriented programming (OOP) that allows a class to inherit properties and behaviors (methods) from another class. In Java, inheritance is implemented using the "extends" keyword.


            class ParentClass {
                // Parent class members
            }
            class ChildClass extends ParentClass {
                // Child class members
            }

What is Inheritance?

Inheritance is a mechanism in which one class acquires the properties (fields) and behaviors (methods) of another class. The class that inherits is called the subclass (or derived class), and the class being inherited from is called the superclass (or base class).

Benefits of Inheritance

  • Code Reusability: Inheritance allows for the reuse of existing code, reducing redundancy.
  • Improved Maintainability: Changes made to the superclass can automatically propagate to subclasses, making maintenance easier.

Types of Inheritance

Java supports several types of inheritance:

  • Single Inheritance: A class inherits from only one superclass.
  • Multi-level Inheritance: A class inherits from a subclass, which in turn inherits from another class.
  • Hierarchical Inheritance: Multiple classes inherit from a single superclass.

Java won't provide support for several types of inheritance:

  • Cyclic Inheritance: A situation where a class inherits from another class, which in turn inherits from the first class. (Not Supported in Java)
  • Multiple Inheritance: A class inherits from more than one superclass. (Not Supported in Java)
  • Hybrid Inheritance: A combination of two or more types of inheritance. (Not Supported in Java)

Example of Inheritance

            class Parent {
               public void newMethod() {
                    System.out.println("Parent class method method.");
                }
            }

            class Child extends Parent {
                
                public void childMethod() {
                    System.out.println("Child class method.");
                }
            }

            public class Main {
                public static void main(String[] args) {
                    Parent par1 = new Parent();
                    par1.newMethod();
                    par1.childMethod(); // This will cause a compile-time error because childMethod() is not defined in Parent class.

                    Child ch1 = new Child();
                    ch1.newMethod(); // This will work because Child class inherits newMethod() from Parent
                    ch1.childMethod(); // This will work because it's a method of the Child class

                    Parent par2 = new Child(); // This is allowed because Child is a subclass of Parent
                    par2.newMethod(); // This will work because Child class inherits newMethod() from Parent
                    par2.childMethod(); // This will cause a compile-time error because childMethod() is not defined in Parent class.

                    Child ch2 = new Parent(); // This will cause a compile-time error because Parent is not a subclass of Child
                }
            }
